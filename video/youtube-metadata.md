## Description

A flagged transaction starts an investigation. Which account needs attention, what happened, and which policy applies?

Follow Meridian Demo Bank's Financial Investigation Copilot from a connected data foundation to an analyst conversation. The walkthrough covers Spark medallion layers, Gold publication to Autonomous AI Lakehouse, notebook and Oracle Analytics dashboards, and a supervisor coordinating SQL, policy RAG and investigation-briefing agents.

See how predefined tools retrieve structured evidence and policy passages, how an Agent Card describes skills, and how AI Registry, Agent Hub and a Streamlit application bring the deployed workflow to users.
